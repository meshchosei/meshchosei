Features EN / DE

USB-OTG & Bluetooth

USB serial (CH340, CP210x, FTDI, nRF52, ESP32, RP2040) or a companion node via BLE/USB.

USB-Serial per OTG oder Companion-Node per BLE/USB.

Remote admin over LoRa

Log in to any repeater in the mesh through your companion, with tagged replies and auto-retry.

Remote-Admin auf jeden Repeater im Mesh.

Mesh-care mode

Temporarily lowers TX power during maintenance; the firmware restores it by itself.

Schonmodus: Sendeleistung temporär senken.

Radio & region

Frequency, bandwidth, SF, CR, TX power and duty cycle with country presets and compliance limits.

Funkparameter mit Länder-Presets und Grenzwerten.

Hardware & antenna

Board detection, antenna and cable-loss presets, ERP/EIRP calculator, power source, LEDs.

Board-Erkennung, Antennen-Presets, ERP/EIRP.

Routing & regions

Forwarding, path hash mode, loop detection, adverts and full region management.

Weiterleitung, Adverts, Regionen-Verwaltung.

Packet filters

Blacklist (Dutch MeshCore) and whitelist for channels, prefixes, senders, text, hops, age.

Paket-Filter: Blacklist und Whitelist.

CLI console

Free command input with a complete, translated command reference.

CLI-Konsole mit übersetzter Befehlsübersicht.

Backup & restore

JSON backup of all settings, regions and filters; restore only sends differences.

JSON-Backup, Wiederherstellung per Abgleich.

Download & installation EN / DE

  1. Download the APK from the latest release.
  2. Allow installing from this source on Android 8.0+ and open the APK.
  3. Connect your repeater via USB-OTG or pair a companion via Bluetooth, then start the scan.
  1. APK aus dem neuesten Release laden.
  2. Installation aus dieser Quelle erlauben (Android 8.0+) und APK öffnen.
  3. Repeater per USB-OTG anschließen oder Companion per Bluetooth koppeln, Scan starten.
